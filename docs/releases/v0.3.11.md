# Windhawk Inspector v0.3.11

First stable GitHub release of Windhawk Inspector, a free browser-based source code analyzer for Windhawk mods.

## Main features

- Analyze Windhawk C++ source from a mod URL, a local file, or pasted code.
- Review detected Windows APIs with clear explanations, source references, and colored activity icons.
- Compare two versions of the same mod. Choose earlier versions from the official GitHub history when available, or provide an earlier source manually.
- Inspect the full source code or switch to a smaller view around the selected lines.
- Export JSON and standalone HTML reports, including the full SHA-256 hash.
- View parser coverage and limits so missing detections are not hidden.

## Quality and security

- Expanded detection for WindhawkUtils hooks, file attribute checks, and Windows Shell file associations.
- Added regression tests for parser recovery, version comparison, and source viewing.
- Fixed the Content Security Policy for public GitHub version history.
- Patched the Vitest development dependency and improved C++ symbol parsing.
- Added a dependency lockfile, reproducible `npm ci` builds, and a security reporting policy.
- Passed a Chromium browser smoke test using three real Windhawk mods and the main input methods.

## Important limitations

Windhawk Inspector performs static source analysis. It does not run mods or scan compiled binaries, and it cannot guarantee that a mod is safe. Some macros, indirect calls, dependencies, and parser recovery regions may be missed. GitHub version history depends on API availability and rate limits.
