# Security Policy

## Supported versions

Security fixes are considered for the latest published Windhawk Inspector release. Older versions might not receive patches.

## Report a vulnerability

Please report security issues privately using **Security → Report a vulnerability** on the [Windhawk Inspector repository](https://github.com/luizbizzio/windhawk-inspector/security), if that option is available.

If private reporting is not enabled, [open an issue](https://github.com/luizbizzio/windhawk-inspector/issues/new) **without sensitive details**, asking for a private reporting channel. Do not post an exploit, unpublished vulnerability, private code, tokens, passwords or personal data in a public issue.

A useful report includes:

- Affected version, URL or commit
- Steps to reproduce, with a minimal non-sensitive example
- Expected and observed behavior
- Potential impact, including any affected browser or platform

Please allow the issue to be investigated before publishing detailed reproduction steps.

## Scope

Reports about source URL handling, browser-side processing, HTML/JSON export, dependencies, source viewing and the C++ parser are relevant.

Windhawk Inspector is a **static source-code analysis tool**, not an antivirus, a sandbox or a guarantee that a mod is safe. Missing findings are not evidence of safety.

The project does not ask users to submit private mod source files or secrets. Public GitHub issues must use safe, minimal examples.
